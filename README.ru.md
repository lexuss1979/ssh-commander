# ssh-commander

[English](README.md) · **Русский**

Локальный веб-инструмент для управления удалённым сервером по SSH: терминал, файловый менеджер, Docker Explorer и AI-агент. Запускается через Docker, слушает только localhost и защищён паролем.

## Возможности

- **Терминал** — полноценный PTY через xterm.js; сессия переживает перезагрузку вкладки; кнопка «Обновить сессию» переустанавливает SSH-подключение (применяет новые группы и права).
- **Файловый менеджер** — просмотр, загрузка/скачивание, редактирование, создание, переименование, удаление, chmod (SFTP).
- **Docker Explorer** — контейнеры, образы, volumes, сети; запуск, остановка, рестарт, удаление, pull, run, live-логи (docker CLI по SSH).
- **AI-агент** — OpenAI-совместимый API с tool calling. Команды чтения выполняются автоматически, изменения (запись файлов, запуск/удаление контейнеров, любые небезопасные команды) — только после подтверждения в интерфейсе. Для каждого профиля ведёт `MEMORY.md` (важные находки из прошлых сессий, автозагрузка в контекст при старте).
- **Несколько серверов** — профили SSH с паролем или ключом.

## Быстрый старт

```bash
cp .env.example .env
# отредактируйте .env: APP_PASSWORD, при необходимости AI_API_KEY и AI_MODEL

# положите SSH-ключи в папку keys/ (если используете ключи)
cp ~/.ssh/id_rsa keys/
# либо пропустите этот шаг и импортируйте ключ позже через UI
# (форма сервера → «Импортировать…» — сохранится в keys/ с правами 0600)

docker compose up -d --build
```

Откройте [http://localhost:8080](http://localhost:8080), войдите с паролем из `.env`, добавьте сервер и работайте.

> Собирать фронтенд вручную не нужно — Dockerfile собирает его внутри образа.
> Если в браузере появляется «Cannot GET /», значит контейнер запущен со старой
> версией образа: выполните `docker compose up -d --build` ещё раз (флаг `--build`
> обязателен после изменения кода).

## Конфигурация

Переменные окружения задаются через `.env` (шаблон — `.env.example`); внутри контейнера — через `environment` в `docker-compose.yml`.

| Переменная | По умолчанию | Описание |
|---|---|---|
| `APP_PORT` / `APP_HOST` | `8080` / `0.0.0.0` | Порт и адрес HTTP/WS сервера |
| `APP_PASSWORD` | `admin` | Пароль веб-интерфейса |
| `DATA_DIR` | `/data` (docker) | Каталог с `profiles.json`, `db-connections.json`, `ai-dialogues.json`, `memory/` и т.п. |
| `KEYS_DIR` | `/keys` (docker) | Каталог с SSH-ключами |
| `WEB_DIST` | авто-определение | Путь к собранному фронтенду |
| `AI_API_BASE` | `https://api.openai.com/v1` | Базовый URL OpenAI-совместимого API |
| `AI_API_KEY` | — | Ключ API (без него агент недоступен) |
| `AI_MODEL` | `gpt-4.1-mini` | Модель агента |
| `AI_MAX_STEPS` | `30` | Лимит шагов агента |
| `AI_TEMPERATURE` | `0.2` | Температура модели |
| `AI_SEARCH_API_BASE` | пусто | Anthropic-совместимая база веб-поиска для агента (у DeepSeek — `https://api.deepseek.com/anthropic`, тот же `AI_API_KEY`). Пусто — поиск выключен, инструмент `web_search` модели не объявляется |
| `AI_SEARCH_MODEL` | `deepseek-v4-flash` | Модель для веб-поиска (серверный инструмент `web_search_20260209`) |
| `AI_LANG` | `ru` | Язык агента: системный промпт и инструкция плана. `en` — английский; неизвестные значения → `ru` |
| `TUNNEL_PORT_MIN` / `TUNNEL_PORT_MAX` | `10000` / `10049` | Диапазон портов для SSH-туннелей (локальный конец) |

Профили серверов хранятся в `data/profiles.json` (volume `./data`), диалоги агента — в `data/ai-dialogues.json`, память агента — в `data/memory/<profileId>/MEMORY.md`; ключи монтируются из `./keys` в `/keys` внутри контейнера. В профиле путь к ключу указывается как путь внутри контейнера, например `/keys/id_rsa`. Ключ можно импортировать прямо из веб-интерфейса (форма сервера → «Импортировать…») — он сохраняется в `./keys` с правами `0600`; содержимое ключей через API не отдаётся.

## Безопасность

- Сервис публикуется только на `127.0.0.1` — недоступен из сети.
- Вход по паролю из `.env`, httpOnly cookie, rate-limit попыток логина.
- AI-агент не выполняет мутирующие действия без подтверждения; read-only команды фильтруются deny-листом (удаление, запись, управление системой, конвейеры и подстановки запрещены).
- Агент записывает в `MEMORY.md` только факты и находки; секреты (пароли, ключи, токены) в память не попадают — это запрещено системным промптом.
- Пароли SSH и passphrase ключей хранятся открытым текстом в `data/profiles.json` — это локальный однопользовательский инструмент, не выкладывайте volume наружу.

## Разработка

```bash
# сервер (порт 8080)
cd server && npm install && npm run dev

# фронтенд с hot-reload (порт 5173, проксирует /api и /ws на 8080)
cd web && npm install && npm run dev
```

Тесты сервера: `cd server && npm test`.
