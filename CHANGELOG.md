# Изменения

## Не выпущено

## 0.1.3 — 2026-10-08

- Уровни доступа AI-агента — per-dialogue: у поля ввода панели агента селектор «Подтверждать всё» / «Подтверждать когда необходимо» / «Полный доступ» с цветовой индикацией (зелёный/оранжевый/красный). По умолчанию — средний режим: безопасные действия (память, неразрушающие операции с контейнерами, запись вне системных путей) выполняются автоматически с бейджем «авто», произвольные команды, подключение серверов и запись в системные/sensitive-пути — по-прежнему с подтверждением. «Полный доступ» включается только с подтверждением осознания рисков; при root/sudo-профиле (или недоступной проверке привилегий) — с усиленным предупреждением и обязательным чекбоксом. Режим сохраняется в диалоге и переключается на лету.
- Редакция секретов, allow-лист read-only команд, таймауты и лимиты вывода агента неизменны во всех режимах.

Форматы данных приложения не менялись (у диалогов добавилось опциональное поле режима, старые файлы читаются без изменений). Перед обновлением остановите прежний экземпляр и сохраните `data/` и `keys/`; два экземпляра не должны писать в один каталог.

## 0.1.2 — 2026-10-06

- Исправлен режим планирования агента: после подтверждения плана переключатель «План» оставался включённым, и следующее сообщение снова уходило на планирование вместо выполнения. Теперь подтверждение плана выключает режим.
- Обнаруживаемость функций: расширенные пустые состояния (серверы — со ссылкой на «Управление серверами», bootstrap и импорт бэкапа; агент — режим «План» и подстановка по Tab; туннели — с кнопкой создания), пояснение формата файла переноса серверов, одноразовые контекстные подсказки (подключение второго сервера к диалогу, скачивание папок целиком, закрепление логов) — показываются один раз и гаснут при использовании функции.
- Комментарии во всём коде и имена тестов переведены на английский для opensource-контрибьютеров; описания инструментов AI-агента стали двуязычными и подбираются по языку сессии (ранее при английском интерфейсе модель получала схемы с русскими описаниями). Поведение приложения не изменилось.
- Отдельный пресет OpenCode Go для ключа подписки: стабильный идентификатор сессии, Chat Completions и автоматический выбор Responses для поддерживаемых моделей. Ошибки потокового API отображаются в интерфейсе, в том числе при HTTP 200.
- Смена модели без повторного ввода сохранённого API-ключа. Успешное сохранение настроек отображается зелёным уведомлением в обеих темах.
- Документация ru/en: поддержка и ограничения моделей OpenCode Go, рекомендация DeepSeek по опыту проекта.
- Обновлены транзитивные зависимости фронтенда и сервера для устранения уязвимостей, найденных npm audit (в т.ч. proxy-addr и source-map-js).

Форматы данных приложения не менялись. Перед обновлением остановите прежний экземпляр и сохраните `data/` и `keys/`; два экземпляра не должны писать в один каталог.

## 0.1.1 — 2026-09-10

- Готовые образы GHCR для `linux/amd64` и `linux/arm64`, отдельный release Compose с закреплённой версией и loopback-портами. Сборка из исходников и dev-режим сохранены.
- CI на push/PR: сборки, unit-тесты, lint и audit. Выпуск образов из проверенного релизного коммита с проверкой запуска обеих архитектур; ARM64 проверяется через QEMU.
- Docker runtime и CI переведены на Node.js 22 LTS вместо Node.js 20 с завершённой поддержкой.
- Инструкции установки без Git/Node/npm, резервного копирования, обновления и перехода со сборки на образ на русском и английском.
- SECURITY.md, CONTRIBUTING.md, формы bug/feature и приватный канал сообщений об уязвимостях; два PNG актуального интерфейса.

Форматы данных приложения не менялись. Перед обновлением остановите прежний экземпляр и сохраните `data/` и `keys/`; два экземпляра не должны писать в один каталог. Пароль приложения и AI-конфигурация сохраняются в `data/settings.json`, изменение seed-переменных окружения их не заменяет.

## 0.1.0 — 2026-09-10

Первый публичный релиз `v0.1.0`.

### Основные возможности

- Локальное однопользовательское приложение: запуск через Docker Compose, пароль и первоначальная настройка в браузере.
- SSH-терминал со вкладками, историей команд и восстановлением сессий при перезагрузке страницы.
- Файловый менеджер SFTP: передача файлов и каталогов, встроенный редактор, поиск, живые логи и анализ занятого места.
- Docker Explorer: контейнеры, образы, volumes, сети, Compose v2, терминал контейнера и follow логов.
- Консоли PostgreSQL/MySQL, службы systemd, Nginx, cron, процессы, обновления пакетов и SSH-туннели.
- AI-агент с собственным ключом OpenAI-совместимого API: read-only диагностика, подтверждение изменений, планирование, память по серверам и учёт расходов.
- Русский и английский интерфейсы, тёмная и светлая темы, единая модалка настроек.
- Три скринкаста в README: новый сервер до работающего сайта на Nginx, диагностика и очистка диска с подтверждением, установка до работающего SSH-терминала.

### Подготовка к публикации

- Обновлены инструменты разработки: Vitest до `4.1.11`, транзитивный `js-yaml` до `4.3.2` для устранения известных уязвимостей.
- Проверена история Git; разбор тестовых срабатываний сканера и порядок повторной проверки приведены в [отчёте готовности](docs/publication-readiness.md).

### Ограничения

Приложение предназначено только для локального использования одним пользователем.
Пароли SSH/БД и ключ AI хранятся в локальном volume открытым текстом.
Запросы агента и результаты инструментов передаются выбранному AI-провайдеру.
Не публикуйте порт приложения или каталог `data/` в интернете.
Поддержка предоставляется по возможности, без SLA; лицензия MIT.
