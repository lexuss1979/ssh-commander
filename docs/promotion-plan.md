# План: минимальное продвижение (open-source, некоммерческое)

> **Статус: план, результат обсуждения с автором; ждёт решения
> «публиковать/не публиковать».** Цель автора: не слава и не коммерция, а
> «дать пинок проекту, чтобы потихоньку набирал аудиторию» — разовые
> действия, без непрерывной работы. Формула публикации: «дарю то, что уже
> сделано», с честным дисклеймером поддержки в README.

## Пререквизиты (обязательно до открытия репозитория)

1. **Аудит истории git на секреты.** В `keys/` и `data/` — реальные ключи
   и пароли; они в `.gitignore`, но нужно убедиться, что ни один коммит их
   не содержал (проверка всей истории, не только рабочего дерева).
   Неопционально.
2. **Лицензия MIT** (стандарт для таких инструментов), файл `LICENSE`.
3. **Дисклеймер безопасности в README — крупно**: localhost-only по
   дизайну, пароли открытым текстом в `data/`, туннели на `127.0.0.1` без
   авторизации, не выставлять в интернет. Без этого кто-нибудь опубликует
   панель наружу и обгорит — шлейф прилетит проекту.
4. **Дисклеймер поддержки**: «публикуется как есть, поддержка по
   остаточному принципу, PR приветствуются». Легитимно закрывает вопрос
   issue/PR на годы вперёд.
5. **Английский UI** — `docs/i18n-plan.md` (фазы 1–2). Без него публикация
   теряет большую часть смысла.
6. Репозиторий уже на GitHub (приватный) — «публикация» = перевод в public
   после пунктов 1–5.

## Уровень 0 — фундамент (1–2 вечера, разово; без него остальное не работает)

- **Английский README**: первый экран решает всё (у посетителя ~15 секунд):
  что это, GIF-скринкаст, запуск за 2 минуты (`docker compose up`).
  GIF, где агент по запросу «почему заполнен диск» сам находит ответ и
  просит подтверждение перед мутацией — сильнее любого текста.
- **GitHub-топики и описание**: `selfhosted`, `ssh`, `devops`, `ai-agent`,
  `homelab`, `termius-alternative`, `docker`. Индексируется поиском.
- **Релизы с человеческими changelog** — признак живого репозитория.

Это пассивный актив: сделал раз — работает годами.

## Уровень 1 — почти бесплатно (пара часов на канал, разово)

- **Reddit**: r/selfhosted и r/homelab — ровно целевая аудитория
  (конкурент Termix вырос именно оттуда). Один пост с GIF, заголовок вида
  «I built a self-hosted SSH manager with an AI agent that asks before
  touching anything». Вечер на пост + вечер на ответы в комментариях.
  Лотерея: от тишины до сотен звёзд, билет бесплатный.
- **Show HN на Hacker News**: та же лотерея с более жирным призом
  (фронтпейдж = тысячи звёзд). Постить в будни утром по ET. Цена попытки —
  10 минут.
- **awesome-листы**: PR в awesome-selfhosted и смежные (awesome-ssh,
  awesome-devops). Есть требования к зрелости репозитория, PR могут
  мариновать месяцами — но это чистый пассивный трафик на годы.

## Уровень 2 — умеренные затраты (вечер-два на канал)

- **Хабр**: русскоязычная аудитория тепло встречает «сделал себе инструмент
  и делюсь». Заголовок почти готов: «Как я перестал гуглить systemctl и
  сделал себе сисадмина». С Хабра бывают переводы и репосты на английском.
- **dev.to / Medium** — слабее по отклику, но индексируется Google.
- **Рассылки и блоги про self-hosted**: selfh.st (есть форма подачи),
  console.dev. Подача — письмо на 5 минут.

## Уровень 3 — дороже, отдача не гарантирована (опционально)

- **YouTube-обзорщики self-hosted** (каналы, делавшие обзоры Termix) —
  письмо с демкой; конверсия низкая, но один обзор = тысячи целевых
  зрителей.

## Чего не делаем

- Product Hunt (формат продуктовых запусков, не OSS-утилит).
- Платная реклама (бессмысленна без коммерческой цели).
- Ежедневные соцсети (это работа, а не «по приколу»).

## Реалистичный план (~4–5 вечеров, размазанных на месяц)

1. Пререквизиты 1–6.
2. Уровень 0 целиком.
3. Один день: r/selfhosted + Show HN; неделю отвечаем на комментарии.
4. PR в awesome-листы.
5. Пост на Хабре.

Дальше проект либо набирает сам (звёзды имеют эффект снежка: GitHub
trending даёт новые притоки), либо нет — и это нормальный исход для
«по приколу». Калибровка ожиданий: без непрерывной работы — единицы звёзд
в месяц в удачном сценарии; сработавший пост на Reddit/HN — сотни разово.

## Дифференциатор (для всех текстов продвижения)

Ниша «self-hosted веб-панель для своих серверов» занята (Termix, Cockpit,
Portainer), но **ни у кого нет AI-агента**; у Termius AI есть, но это
закрытая подписка. Уникальная связка: терминал + файлы + Docker +
nginx/БД/службы + агент, который **просит подтверждение перед каждым
мутирующим действием**, + свой API-ключ, всё локально. Это и есть
сообщение для README, постов и заголовков.
