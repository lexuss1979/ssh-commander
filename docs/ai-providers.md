# Выбор AI-провайдера

[English](ai-providers.en.md) · [README](../README.ru.md)

Провайдер, ключ и модель задаются в **Настройки → AI-агент**. При смене только модели сохранённый ключ вводить заново не нужно. Изменения применяются без перезапуска приложения.

## Рекомендуем DeepSeek

Для повседневной работы агента мы рекомендуем **DeepSeek**. По нашему опыту с задачами администрирования серверов он отвечал в несколько раз быстрее моделей, которые мы пробовали через OpenCode Go. Скорость зависит от модели, размера диалога и нагрузки провайдера: это наблюдение из практики проекта, а не результат универсального бенчмарка.

Выбери пресет **DeepSeek**, введи API-ключ и оставь модель по умолчанию `deepseek-v4-flash` либо укажи другую доступную модель. Веб-поиск у этого пресета включён автоматически.

## Подписка OpenCode Go

ssh-commander поддерживает ключ подписки **OpenCode Go** напрямую: запускать клиент OpenCode не нужно. Выбери пресет **OpenCode Go**, введи ключ подписки и имя модели без префикса `opencode-go/`. Base URL пресета — `https://opencode.ai/zen/go/v1`, модель по умолчанию — `glm-5.3-flash`.

**Поддерживаются не все модели подписки.** Совместимость зависит от протокола, через который OpenCode предоставляет модель:

| Протокол модели | Поддержка в ssh-commander |
|---|---|
| OpenAI Chat Completions | Поддерживается; проверена `glm-5.3-flash`, включая вызовы инструментов. |
| OpenAI Responses | Поддерживается для `gpt-6-luna`, `gpt-5.6-luna`, `grok-4.7`, `grok-4.6`, `muse-spark-1.3-contributor` и `muse-spark-1.2-contributor`; протокол выбирается автоматически. Проверена `gpt-6-luna`, включая вызовы инструментов. |
| Anthropic Messages | Пока не поддерживается. Модели, доступные только через этот протокол, использовать нельзя. |

Список моделей и их endpoint'ов может меняться — сверь выбранную модель с [документацией OpenCode Go](https://opencode.ai/docs/go/#endpoints). Поддержка нового имени модели Responses может потребовать обновления ssh-commander.

Поддержка Go добавлена после готового образа **0.1.1**. До следующего релиза используй [сборку из исходников](installation.md#сборка-из-исходников).

Веб-поиск у пресета Go автоматически не включается. Лимиты подписки и ограничения провайдера модели продолжают действовать: `rate_limit_exceeded` означает превышение лимита запросов или токенов, а `ModelProtocolUnsupported` — несовместимость выбранной модели с протоколом запроса.
